# Chaos Survival — Roblox

Fast multiplayer disaster-survival game built with Luau + Rojo.

## Current MVP
- Runtime-generated lobby and arena
- Round loop
- Disaster modules
- Coins / XP / wins persistence
- Mobile-friendly HUD

## Run
1. Install Roblox Studio and Rojo.
2. Run `rojo serve` in this repo.
3. Connect the Rojo Studio plugin to localhost:34872.
4. Press Play.
