# Store & Marketing Creative Department Review

## Specialist mindset

Review as:
- game marketing creative director;
- thumbnail/icon art director;
- trailer editor;
- mobile storefront conversion designer;
- brand consistency reviewer.

## Principle

Marketing must amplify the real experience, not fabricate a different one.

A player who clicks because of the icon/thumbnail should recognize the promised game within the first minute.

## Core promise to communicate

Chaos Survival should communicate in a glance:
- active survival;
- readable disaster;
- strong arena identity;
- other survivors;
- escalating chaos;
- bright/premium sci-fi visual language.

## Icon requirements

The icon must:
- read at very small size;
- have one dominant focal subject;
- avoid tiny UI/text;
- avoid a collage of all disasters;
- preserve contrast on light/dark platform surfaces;
- look like the actual game.

Recommended subject hierarchy:
1. survivor;
2. one iconic hazard;
3. one arena landmark.

## Thumbnail set

Target 3–5 images with distinct jobs:

1. **Core Survival**
   Character evading a clear hazard.

2. **Double Chaos**
   Two readable hazards, not visual noise.

3. **Social Survival**
   Several survivors in a shared climax/result.

4. **Arena Identity**
   Strong environmental shot showing a Hero landmark.

5. **Clutch / Result**
   Last survivor or survivor constellation.

## Capture rules

Use actual in-game composition whenever possible.

Do not:
- add impossible enemies/gear;
- fake UI rewards;
- exaggerate player count;
- show geometry not present in game;
- use lighting impossible in real gameplay.

Post-processing may improve readability but must not misrepresent the product.

## Trailer structure 15–30 seconds

0–2 s:
- recognizable hook.

2–6 s:
- vote / reveal.

6–15 s:
- movement + hazard escalation.

15–22 s:
- Double Chaos / close call / Final Rush.

22–28 s:
- social result / clutch / invite-a-friend feeling.

End:
- title + clear experience identity.

No long logo intro.

## Mobile storefront test

Review icon/thumbnails at realistic small sizes on phone.

Pass if:
- focal action reads instantly;
- text is not required to understand image;
- images remain distinct from each other;
- visual language matches the game.

## Store copy

Description should answer:
- what do I do?
- what makes it different?
- can I play solo?
- can I play with friends?
- is it fair?

Avoid feature dumping.

## Marketing scorecard /10

- truthfulness;
- icon readability;
- thumbnail variety;
- visual quality;
- game recognition;
- mobile readability;
- trailer pacing;
- social appeal;
- differentiation;
- brand coherence.

Do not finalize marketing before device-certified gameplay visuals exist.
