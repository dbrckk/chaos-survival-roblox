# Cross-Discipline Tool — Attention & Sensory Budget

## Why this exists

A premium game can still feel cheap if every system demands attention simultaneously.

The player has limited:
- visual attention;
- reading capacity;
- audio attention;
- motor attention;
- emotional bandwidth.

This document treats attention like a performance budget.

## Attention channels

### World vision
Used for:
- player position;
- hazard;
- route;
- other survivors.

### HUD vision
Used for:
- timer;
- alive count;
- immediate action;
- short challenge.

### Audio
Used for:
- warning;
- impact;
- movement;
- reward.

### Camera/body
Used for:
- acceleration;
- impact;
- tension.

### Cognitive/meta
Used for:
- progression;
- rewards;
- social;
- economy.

## Phase budget

### Lobby
Allowed:
- world identity: high;
- social: medium;
- meta: medium;
- lethal warnings: none;
- cinematic effects: medium/high.

### Vote
Allowed:
- choice UI: high;
- world ambience: low/medium;
- social presence: medium;
- meta: low.

### READY
Allowed:
- hazard identity/action: high;
- arena strategy: medium;
- world reveal: medium;
- progression: none.

### ROUND
Allowed:
- hazard/world: maximum;
- control feedback: high;
- timer/alive: medium;
- challenge: low;
- meta/social CTA: none;
- decorative VFX: low.

### FINAL RUSH
Allowed:
- hazard: maximum;
- timer: high;
- movement feedback: high;
- everything else: minimum.

### RESULT
Allowed:
- outcome/story: high;
- reward: medium;
- social: medium;
- cinematic spectacle: high;
- next goal: medium.

## Collision rule

If two systems need the same channel at the same time, one must yield.

Examples:
- Final Rush vignette vs critical-health vignette → combine or prioritize.
- Hazard warning sound vs reward sound → hazard wins.
- Result share CTA vs next-round transition → CTA disappears before action phase.
- Master banner vs close-call toast → highest narrative value wins.

## Sensory intensity scale

For every effect assign:
- 0 = none;
- 1 = ambient;
- 2 = noticeable;
- 3 = strong;
- 4 = dominant.

During ROUND:
- no more than one dominant visual event;
- no more than one dominant audio event;
- camera intensity should rarely exceed 2;
- decorative effects should remain 0–1.

## Repetition multiplier

An effect that occurs frequently must have lower intensity.

Suggested rule:
effective fatigue = intensity × frequency × duration.

If fatigue is high:
- shorten;
- lower volume/opacity;
- reduce camera;
- add cooldown;
- vary subtly.

## Review deliverable

For every major phase, list active:
- HUD;
- world VFX;
- audio;
- camera;
- social UI;
- progression UI.

If more than three elements simultaneously demand action, simplify.
