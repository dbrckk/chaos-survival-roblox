CHAOS SURVIVAL — MATRICE DE PERFECTION ET HARMONISATION
=======================================================

Usage
-----
Ce fichier est le tableau de bord de qualité final.
Échelle :
0 = absent/cassé
1 = prototype
2 = fonctionnel
3 = bon
4 = premium
5 = référence / excellent dans le contexte Roblox

IMPORTANT :
Une note sans preuve est provisoire.
Les notes visuelles/tactiles ne peuvent pas atteindre 5 sans test réel appareil/Studio.

Seuils :
- RELEASE BLOCKER : <3 sur une discipline P0.
- PREMIUM BLOCKER : <4 sur une discipline principale.
- "FINAL" : aucune note <4 sur les disciplines principales + preuves release complètes.

HARMONISATION PASS — À FAIRE APRÈS CHAQUE GROS CHANTIER
======================================================================

1. SUPPRIMER
- doublons ;
- VFX sans fonction ;
- texte inutile ;
- systèmes qui ne servent plus ;
- accents visuels concurrents.

2. NORMALISER
- timing animations ;
- easing ;
- UI spacing ;
- corner radius ;
- strokes ;
- couleurs ;
- volume audio ;
- haptics ;
- terminology.

3. RÉÉQUILIBRER
- densité par phase ;
- lumière ;
- audio ;
- particles ;
- rewards ;
- durée intermission/result.

4. COMPARER LES 4 ARÈNES
Si une arène paraît clairement moins finie :
elle devient priorité absolue.

5. COMPARER LES 11 CATASTROPHES
Si une catastrophe paraît moins lisible/mémorable :
elle devient priorité.

6. COMPARER SOLO / MULTI
Solo doit être complet.
Multi doit être plus riche socialement, pas mécaniquement obligatoire.

7. COMPARER MOBILE / DESKTOP
Le mobile ne doit pas recevoir une version "pauvre" du gameplay.
Il peut recevoir moins de décor, jamais moins d'information.

8. TESTER SANS SON
9. TESTER VFX LOW
10. TESTER REDUCE MOTION
11. TESTER PREMIÈRE SESSION
12. TESTER JOUEUR EXPÉRIMENTÉ
13. TESTER 30 MIN
14. TESTER APRÈS FATIGUE VISUELLE

======================================================================
PASS "PENSER DIFFÉREMMENT"
======================================================================

Après avoir résolu les défauts évidents, poser systématiquement :

- Et si on supprimait cette feature ?
- Et si le joueur ne lisait aucun texte ?
- Et si le joueur était seul ?
- Et s'il jouait avec trois amis ?
- Et s'il perdait cinq fois ?
- Et s'il gagnait cinq fois ?
- Et s'il avait le son coupé ?
- Et si son téléphone chauffait ?
- Et s'il était daltonien ?
- Et s'il rejoignait à 5 secondes de la fin ?
- Et s'il ne revenait qu'une semaine plus tard ?
- Et s'il ne voulait jamais ouvrir le shop ?
- Et si le serveur laggait ?
- Et si deux hazards produisaient le même signal ?
- Et si la meilleure amélioration était de réduire plutôt qu'ajouter ?
- Quelle est la chose la plus "cheap" encore visible ?
- Quelle est la chose la plus confuse encore visible ?
- Quelle est la chose la plus générique encore audible ?
- Quel moment mérite d'être partagé mais ne l'est pas ?
- Quel moment est trop long pour sa valeur émotionnelle ?

RÈGLE DE FIN
======================================================================

Ne jamais écrire "5/5" parce qu'une feature existe.
Écrire 5/5 uniquement après preuve.

Quand toutes les disciplines principales sont >=4 :
1. arrêter d'ajouter des features ;
2. faire une passe de suppression ;
3. faire une passe d'harmonisation ;
4. faire une passe fresh-eyes ;
5. certifier devices ;
6. lancer alpha ;
7. corriger uniquement les problèmes observés ;
8. geler release candidate.
